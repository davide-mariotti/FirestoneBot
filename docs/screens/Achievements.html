Estratta senza avviare il gioco, analizzando staticamente Firestone_Data/resources.assets. Ogni riga è un GameObject reale del prefab di questa schermata.

Radice della schermata

Path: Achievements

PathTipoNote
Achievements inattivo Canvas + AchievementsViewController Radice del prefab: è un Canvas con GraphicRaycaster proprio, controllato dallo script AchievementsViewController. Risulta disattivo di default nel prefab: probabilmente viene attivato a runtime solo quando un achievement viene sbloccato, come overlay/toast temporaneo sopra la schermata corrente (non un menu navigabile).

Notifica di achievement completato

Path: Achievements/achievementShown/*

PathTipoNote
Achievements/achievementShown contenitore — Image + AchievementCompletedInteraction Riquadro/card della notifica "achievement completato". Lo script AchievementCompletedInteraction gestisce probabilmente l'animazione di comparsa/scomparsa e l'eventuale interazione al tap; nessun componente Button è presente sul nodo, quindi non è un pulsante nel senso classico.
Achievements/achievementShown/icon immagine — Image Icona dell'achievement sbloccato.
Achievements/achievementShown/name testo TextMeshProUGUI + I2.Loc.Localize Nome/titolo dell'achievement, localizzato (I2 Localization).
Achievements/achievementShown/part testo TextMeshProUGUI Funzione non chiara dal nome ("part"): potrebbe indicare il progresso (es. "X/Y") o la categoria/sezione dell'achievement. Verificare dal vivo.
Achievements/achievementShown/rewardText testo TextMeshProUGUI + I2.Loc.Localize Testo della ricompensa ottenuta per l'achievement, localizzato.
Path radice completo: menusRoot/menuCanvasParent/SafeArea/menuCanvas/menus/Achievements. Nota: il path radice completo non è verificato dal vivo, dedotto solo dal nome del GameObject — trattandosi di un Canvas con proprio GraphicRaycaster e risultando inattivo di default, è plausibile che sia in realtà un overlay globale montato fuori dai menu classici (es. mostrato anche durante la battaglia); da confermare risalendo la gerarchia della scena live.
