💎 Cristallo Arcano

Estratta senza avviare il gioco, analizzando staticamente Firestone_Data/resources.assets. Ogni riga è un GameObject reale del prefab di questa schermata. Il nodo radice ArcaneCrystal risulta inactive nel prefab: è un popup di evento, mostrato/nascosto a runtime dal menu principale.
