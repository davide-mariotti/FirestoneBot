🌳 Albero della Vita (TreeOfLife)

Estratta senza avviare il gioco, analizzando staticamente Firestone_Data/resources.assets. Ogni riga è un GameObject reale del prefab di questa schermata. Il nodo radice TreeOfLife risulta disattivo di default nel prefab: è un popup che viene attivato a runtime dal controller TreeOfLifeViewController. La schermata ha due sotto-tab affiancati nello stesso prefab: submenus/personalTree (albero personale, attivo di default) e submenus/guildTree (albero di gilda, disattivo di default finché non si seleziona il relativo tab).
