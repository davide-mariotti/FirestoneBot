Mini-Events

Mini-events are recurring events that take place every five days and last for three days.

Mini-events

During a mini-event, all players get an event bonus which can be increased by purchasing one of the event packs (see below). All mini-events have a character level requirement to participate. There are the following 11 mini-events:

Icon Event name Bonus/purchase bonus Level
Stardust Miners bring you 20%/150% more meteorites 30

Mass Production The engineer creates 20%/120% more tools 50
Sigils Of Prophecy Playing the Scarab's game with Noble's token will generate 20%/120% more Ancient coins 60

Event packs

During a mini-event, three event packs (essential boost pack, deluxe upgrade pack and elite upgrade pack, which appears after you purchase the first two packs) are offered for platform currency. Each event pack gives extra resources. Purchasing an event pack will also increase the event bonus for the remainder of the mini-event.
