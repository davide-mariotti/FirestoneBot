Events

Events are time-limited specials which will give extra or unique rewards to the players participating in them.

Calendar Events

Calendar events are recurring events that take place at certain times in the calendar year and last for two weeks. These events are available to players who have reached character level 10. In the even months of the year, the following events take place:

Icon Event name Start time Description Rewards
Valentine's Event February Lino, the love goblin brings you chocolates which can be exchanged in the chocolate factory. Valentine's decorations. Chests, currencies, avatars
Spring Event April Sandy, the little gardener brings you flowers which can be exchanged in the tree house. Spring decorations. Chests, currencies, avatars
Tropicana Event June Bruce, the shell collector brings you shells which can be exchanged in the souvenir shop. Summer decorations. Chests, currencies, avatars
Space Event August Rocky, the astral explorer brings you energy crystals which can be exchanged in the observatory. Space decorations. Chests, currencies, avatars
Halloween Event October Maxwell, the pumpkin head brings you pumpkins which can be exchanged in the witch's hut. Halloween decorations. Chests, currencies, avatars
Winter Festival Event December Comet, the winter navigator brings you candy which can be exchanged in the winter shop. Winter festival decorations. Chests, currencies, avatars

In the remaining months, the following event takes place:

Icon Event name Start time Description Rewards
Decorated Heroes Event January, March, May, July, September, November Complete daily challenges to get stars of recognition, which then can be exchanged in the event shop, and a medal of courage. Chests, currencies, hero skins

Mini-Events

Mini-events are recurring events that take place every five days and last for three days. All mini-events have a character level requirement to participate. During a mini-event, all players will get an event bonus which can be increased by purchasing one of the event packs. In addition, for each of the three days there is a random event challenge which will give contracts and specific event reward when completed. There are the following mini-events:

Icon Name Bonus Rewards Level
Stardust Miners bring more meteorites 30
Primordial Elements Dragons bring more beers 30
Ethereal Miners Pickaxes are generated faster 50
Team Effort Expeditions give more guild coins and expedition tokens 30
Mechanical Superiority Campaign loots yield more emblems of valor and blueprints 50
World Domination Mystery missions with mystery boxes appear on the world map 30
Guardians of Destiny Guardian training is faster and gives more xp 30
Blessing of the Eternals Enemies drop more gold and you get more firestones when prestiging 30
Champions of Alandria Heroes and guardians get a all main attributes bonus and the chance to skip a stage is increased 30
Mass Production The engineer creates more tools 50
Sigils Of Prophecy Playing the Scarab's game with Noble's token will generate more Ancient coins. 60

New Server Events

New server events are one-time competition events which take place whenever a new game server is opened. Only players on the new server who are at the top of a certain leaderboard at the end of the event recieve rewards

Icon Event name Duration Leaderboard Rewards
Server opening event 30 days Max stage Chests, currencies
Server warfront event 9 weeks Campaign stars Chests, currencies

Special Events

Special events are one-time events that happened on special occasions.

Icon Event name Duration Description Rewards
Warfront expansion event 13 April 2021 - 15 May 2021 Competition event to celebrate the warfront expansion. Players who were in the top 50 in the campaign stars leaderboard (separately on each server) received rewards. Chests, currencies
5 Year Anniversary Event 1 April 2024 - 15 March 2025 (2 weeks) Being online awards you activity coins which then can be exchanged in the event shop. Chests, currencies, avatars, hero skins
6 Year Anniversary Event 1 April 2025 - 15 March 2026 (2 weeks) Being online awards you activity coins which then can be exchanged in the event shop. Chests, currencies, avatars, hero skins
Frostfire Festival Event 4 December 2025 - 19 December 2025 Open presents to receive rewards. Chests, currencies, avatar

New players will get the following event instead of the anniversary event.

Icon Event name Duration Description Rewards
New Player Event 2 weeks Being online awards you activity coins which then can be exchanged in the event shop. Chests, currencies, avatars, hero skins
