⬆️ Potenziamenti (Upgrades)

Estratta senza avviare il gioco, analizzando staticamente Firestone_Data/resources.assets. Ogni riga è un GameObject reale del prefab di questa schermata. Il nodo radice Upgrades risulta disattivo di default nel prefab: è un popup/menu che viene attivato a runtime dal controller UpgradesViewController.
